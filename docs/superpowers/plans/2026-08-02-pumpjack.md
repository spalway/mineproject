# PUMPJACK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship a working Solana devnet site where users deploy real SOL into an 8×8 grid whose strikes are resolved by the live pump.fun launch firehose.

**Architecture:** A single long-lived Next.js node process. `instrumentation.ts` boots a runtime that holds a persistent websocket to PumpPortal, buckets every incoming mint into a sector by its own pubkey, and resolves an epoch every 60 seconds against SQLite. All mechanic logic is pure functions over a state snapshot; the browser receives updates over SSE. Deploys are real signed SOL transfers verified server-side by re-reading the chain.

**Tech Stack:** Next.js 15 (App Router) · TypeScript · Tailwind v4 · shadcn/ui · `@solana/web3.js` · `@solana/wallet-adapter-react` · `better-sqlite3` · `ws` · `vitest`

## Global Constraints

- Spec of record: `docs/superpowers/specs/2026-08-02-pumpjack-design.md`. Constants come from §3.8 and are defined once in `src/lib/config.ts`.
- Network is devnet. `NETWORK` env var (`devnet` | `mainnet`) is the only switch; no network-specific code paths.
- **Never synthesize on-chain or feed data.** No seeded TVL, no placeholder mints, no mock activity in the shipped app. Outages render `DARK` (spec §3.6).
- Section names are exactly `FIELD`, `FLOW`, `DEPTH`, `RIFT`, `VEIN` — no articles, all caps in UI.
- Mechanic vocabulary in all UI copy: sector, epoch, grade, strike, rig, draw, depth, rift, vein.
- All monetary math is integer lamports. Never use floats for money.
- Payout allocation must satisfy exact conservation: sum of all allocations equals the pot exactly.
- Amber is reserved exclusively for vein state. Pump green is the only other accent.
- Node 20+. Commit after every task.

```ts
import { PublicKey } from '@solana/web3.js'
import { CONFIG } from './config'

export function sectorOf(mint: string): number {
  return new PublicKey(mint).toBytes()[0] % CONFIG.SECTOR_COUNT
}

export function coordsOf(sector: number) {
  return { row: Math.floor(sector / CONFIG.GRID_SIZE), col: sector % CONFIG.GRID_SIZE }
}

export function sectorAt(row: number, col: number): number {
  return row * CONFIG.GRID_SIZE + col
}

export function neighbors(sector: number): number[] {
  const { row, col } = coordsOf(sector)
  const n = CONFIG.GRID_SIZE
  const out: number[] = []
  if (row > 0) out.push(sectorAt(row - 1, col))
  if (row < n - 1) out.push(sectorAt(row + 1, col))
  if (col > 0) out.push(sectorAt(row, col - 1))
  if (col < n - 1) out.push(sectorAt(row, col + 1))
  return out
}
```
